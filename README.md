# EXIF Date Sync

作者：[@tanahata](https://x.com/tanahata) ／ ライセンス：[MIT](LICENSE)（独自コードのみ）。ExifToolなどの外部ソフトウェア・ライブラリにはそれぞれのライセンスが適用されます。

**EXIFの撮影日時をファイルの変更日時へ反映する、完全無料の単機能アプリです。** macOSとAndroidに対応しています。画像本体、EXIF/XMP、ファイル名は書き換えません。

## 入手・インストール

配布先は[GitHub Releases](https://github.com/tanahata/exif-date-sync/releases)です。対応OS、CPU、SHA-256は各リリースに記載しています。

- **macOS**：ZIPをダウンロードして展開し、アプリを起動します。別途[ExifTool](https://exiftool.org/)のインストールが必要です（Homebrew使用時：`brew install exiftool`）。Apple Developer ID署名・公証は行わないため、初回起動時にmacOSの確認が必要になる場合があります。配布元とファイルを確認したうえで、[Apple公式のアプリ個別許可手順](https://support.apple.com/ja-jp/102445)を利用してください。macOS全体の保護機能は無効にしないでください。警告内容が「破損」や「マルウェア」を示す場合は無理に開かないでください。
- **Android**：GitHub Releasesの署名済みAPKをダウンロードしてインストールします。Android側でブラウザ等からのインストール許可が必要になる場合があります。利用時には対象フォルダへのアクセス権限が必要です。署名が異なるアプリには上書きインストールできません。

写真は事前にバックアップし、最初はコピーした画像で動作を確認してください。

## 使い方

1. 対象フォルダを選んでスキャンします。サブフォルダの対象・除外を選べます（初期OFF）。macOSではRAWの検索対象を切り替えられます（初期ON）。
2. 一覧で撮影日時と現在の変更日時を確認し、更新する画像だけチェックします。Macは行をクリックするか上下矢印キーで右欄のプレビューを切り替えます。Androidはファイル名をタップしてプレビューを開き、左右スワイプまたは「前へ」「次へ」で一覧の順に移動できます。どちらも関連付けアプリで画像を開けます。サムネイルを取得できない形式でも日時の一覧は維持します。
3. **件数を確認して更新**します。直近の1バッチに限りUndo可能です。スキャンが不完全な場合は更新できません。

大量ファイルの一覧は、Macでソート・絞り込み可能なコンパクトな4列表、Androidで3行の一覧です。スキャン中は検出順、完了後は指定順で表示します。一覧の各行にはサムネイルを表示しません。

## 対応環境と制約

| 項目 | macOS | Android |
| --- | --- | --- |
| EXIF読取 | [ExifTool](https://exiftool.org/)を別途インストール（例：`brew install exiftool`） | AndroidX ExifInterface |
| ファイル変更日時 | ExifTool／必要時はFoundationを利用 | Android標準のmtime更新 |
| フォルダ | 明示選択したフォルダ（必要時は配下を含む） | 本体共有ストレージ内`DCIM`／`Pictures`／`Download`配下 |
| Undo | 最新1バッチ（ローカルJSON） | 最新1バッチ（ローカルSQLite） |
| プレビュー | macOS標準のQuick Lookで取得できる縮小画像 | Android標準のThumbnailUtilsで取得できる縮小画像 |

- 撮影日時はEXIF `DateTimeOriginal`のみ採用します。明示的なタイムゾーンオフセットがあれば使用し、なければJSTとみなします。1970年より前、日時不明・不正・読取不能な画像は更新しません。
- RAWの日時・縮小画像を取得できるかはファイル・OS・使用ライブラリによって異なります。AndroidでDNGの一部を読めない事例を確認しています。独自のRAW解析や日時の推測補完は行いません。
- macOSではmtime更新に伴い**ファイルの作成日時（birthtime）が変化する場合**があります。Undoで戻せるのはmtimeだけです。
- Androidの一括更新には現行実装上、**1バッチ20,000件**の技術的上限があります。有料版への誘導や無料枠の制限はありません。
- 動画・NAS・クラウド・SDカード・時差補正・フォルダ振り分け・リネーム・メタデータ編集には対応しません。
